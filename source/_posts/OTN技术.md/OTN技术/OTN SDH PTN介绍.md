## 二、SDH 设备

### 2.1 技术特点

```text
SDH 设备核心特征:

  ┌──────────────────────────────────────────────────────────┐
  │  技术基础: TDM \(时分复用\)                                 │
  │  交换粒度: VC-12 \(2M\) / VC-4 \(155M\)                     │
  │  典型速率: STM-1\(155M\) / STM-4\(622M\) / STM-16\(2\.5G\)     │
  │  管道特性: 刚性管道 \(固定时隙，独占带宽\)                    │
  │  保护能力: MSP/SNCP，\< 50ms 倒换                          │
  │  OAM 能力: 完善的段开销/通道开销监控                       │
  └──────────────────────────────────────────────────────────┘
```

|场景|关键需求|SDH 优势|
| ----------| ----------------| ------------------------------|

## 三、PTN 设备

### 3.1 技术特点

```text
PTN 设备核心特征:
  ┌──────────────────────────────────────────────────────────┐
  │  技术基础: 分组交换 (Packet Switching)                    │
  │  协议基础: MPLS-TP / PBB-TE                              │
  │  交换粒度: 分组 (Packet) / PW (伪线)                      │
  │  典型接口: FE/GE/10GE                                     │
  │  管道特性: 弹性管道 (统计复用，按需分配)                    │
  │  QoS 能力: 多级队列、流量整形、拥塞管理                     │
  │  时钟同步: 1588v2 / SyncE (支持频率+相位同步)              │
  └──────────────────────────────────────────────────────────┘
```

### 3.2 应用场景

```text
场景1: 4G/5G 移动回传
──────────────────────────────────────────────────
  需求: 基站到核心网的回传承载
  基站流量特征:
  ├── 突发性强 (用户刷视频/下载时流量暴增)
  ├── IP 化 (基站侧全是 IP 包)
  ├── 需要时间同步 (TDD 基站要求 ±1.5μs)
  └── 带宽动态变化 (4G: 100M1G, 5G: 1G10G)
  PTN 优势:
  ├── 分组交换 → 适配 IP 化流量，统计复用提高利用率
  ├── 1588v2 → 满足 TDD 基站时间同步需求
  ├── QoS → 区分控制面/用户面优先级
  └── 弹性带宽 → 按需扩容，不需固定时隙
  组网:
  ┌──────┐     ┌──────┐     ┌──────┐     ┌──────┐
  │ 基站1 │     │ 基站2 │     │ 基站3 │     │ 核心网│
  │ 4G   │     │ 4G   │     │ 5G   │     │      │
  └──┬───┘     └──┬───┘     └──┬───┘     └──┬───┘
     │            │            │            │
     ▼            ▼            ▼            ▼
  ┌──────────────────────────────────────────────┐
  │              PTN 承载网络                      │
  │                                               │
  │  接入层        汇聚层         核心层            │
  │  PTN ──── PTN ──── PTN ──── PTN ──── 核心网   │
  │  (GE)       (10GE)      (10GE/100GE)          │
  └──────────────────────────────────────────────┘
──────────────────────────────────────────────────
场景2: 企业 IP 专线 / VPN
──────────────────────────────────────────────────
  需求: 企业多分支互联，IP 化组网
  PTN 优势:
  ├── E-Line / E-LAN 业务类型
  ├── MPLS-TP 伪线 → 模拟专线体验
  ├── 统计复用 → 多条企业专线共享带宽，降低成本
  └── QoS → 保障关键业务优先级
  ┌──────────┐              ┌──────────┐
  │ 企业总部  │              │ 企业分支  │
  │ (GE口)   │══ PTN VPN ══│ (GE口)   │
  │          │              │          │
  └──────────┘              └──────────┘
──────────────────────────────────────────────────
场景3: 政企混合承载
──────────────────────────────────────────────────
  需求: 同时承载 2M 专线 + IP 业务
  PTN 通过 CESoPSN (Circuit Emulation over Packet):
  ├── 2M 业务 → 封装成分组 → 在 PTN 中传输
  ├── IP 业务 → 原生分组传输
  └── 两种业务在同一张 PTN 网中承载
```

### 3.3 PTN 适用场景总结

|场景|关键需求|PTN 优势|
| ------------| ---------------------------| ----------------------------|
|4G/5G 回传|IP 化、时间同步、弹性带宽|分组交换、1588v2、统计复用|
|企业 VPN|多分支互联、QoS|MPLS-TP 伪线、多级 QoS|
|政企混合|2M + IP 混合承载|CESoPSN 仿真|
|城域接入|多业务汇聚|灵活接入、弹性带宽|

## 四、OTN 设备

### 4.1 技术特点

```text
OTN 设备核心特征:

  ┌──────────────────────────────────────────────────────────┐
  │  技术基础: WDM \(波分复用\) + TDM \(ODUk 时分\)               │
  │  交换粒度: 波长 \(OCH\) / ODUk \(1\.25G\~100G\)                │
  │  典型速率: OTU1\(2\.5G\)/OTU2\(10G\)/OTU3\(40G\)/OTU4\(100G\)    │
  │           OTU4flex\(400G\)                                  │
  │  管道特性: 超大刚性管道 \(波长级/子波长级\)                    │
  │  保护能力: OMS/OCH 保护，\< 50ms                           │
  │  FEC 能力: SD-FEC / HD-FEC \(超强纠错\)                     │
  │  传输距离: 无电中继 80\~120km，超长距 1000km+               │
  └──────────────────────────────────────────────────────────┘
```

  OTN 优势:
  ├── 单波长 100G/400G → 超大容量
  ├── 80 波 DWDM → 单纤 8T\~32T 总容量

  └── OCH 保护 → 波长级保护倒换

  └──────┘                              └──────┘
       │  ┌────┐  ┌────┐  ┌────┐  │
       └──│ OA │──│ OA │──│ OA │──┘
          └────┘  └────┘  └────┘

  需求: 城域核心节点之间 10G/100G 互联
  
  OTN 优势:
  ├── ODUk 交叉 → 子波长粒度调度 \(1\.25G\~100G\)
  ├── 承载 PTN/SDH/IP 等各种客户信号
  ├── 低时延 → 适合数据中心互联
  └── 完善的 OAM → 端到端性能监控

  ┌──────┐     ┌──────┐     ┌──────┐
  │ 核心A │─────│ 核心B │─────│ 核心C │

  └──┬───┘     └──┬───┘     └──┬───┘
     │            │            │
     ▼            ▼            ▼
  ┌──────┐     ┌──────┐     ┌──────┐

──────────────────────────────────────────────────
场景3: 数据中心互联 \(DCI\)
──────────────────────────────────────────────────
  需求: 两个数据中心之间 100G/400G 互联
  
  OTN 优势:
  ├── 100G/400G 单波 → 满足大数据量同步/备份
  ├── 低时延 → OTN 转发时延 \< 1ms \(100km\)
  ├── 硬隔离 → 不同租户业务互不干扰
  └── 高可靠 → 波长级保护

  ┌──────────┐                    ┌──────────┐
  │ 数据中心A │════ 100G OTN ════│ 数据中心B │

ODUk 速率:

### 2 帧结构关键数字

```text
SDH:
  STM-1 帧: 9行 × 270列 \= 2430字节
  STM-N 帧: 9行 × 270×N列
  帧频: 8000帧/秒 \(125μs/帧\)
  VC-4 净荷: 9行 × 260列 \(去POH 1列\)
  VC-4 承载: 63×VC-12 \= 63×2M

OTN:
  OTUk 帧: 4行 × 4080列 \= 16320字节
  FAS: 6字节 \(帧对齐\)
  MFAS: 1字节 \(复帧对齐\)
  SM: 3字节 \(段监控\)
  FEC: 4行 × 256列 \= 1024字节
  帧频: 与 STM-64 对齐 \(约 8000帧/秒\)
```

### 3 保护倒换关键参数

```text
  倒换时间: \< 50ms \(所有保护类型\)
  
  MSP 1+1: 双发选收，不需要 APS 协议
  MSP 1:1: 单发单收，需要 APS \(K1/K2\)
  SNCP:    双发选收，源端桥接，宿端选收
  
  APS 字节: K1 \(请求倒换\) + K2 \(确认倒换\)
  
  倒换条件:
  ├── SF \(Signal Fail\): 信号丢失/严重误码
  └── SD \(Signal Degrade\): 信号劣化 \(误码率超阈值\)
```
