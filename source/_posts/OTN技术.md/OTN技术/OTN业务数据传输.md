# OTN业务数据传输

# 光电转换

## 一、先理解核心问题

```text
信号在传输设备中，什么时候需要"电"，什么时候用"光"？

  光信号 ──▶ 需要处理/调度 ──▶ 要不要转成电？

  两种路线:
  ├── 电交叉: 光→电→交叉调度→电→光 (OEO)
  └── 光交叉: 光→直接光层调度→光 (OOO)
```

---

## 二、光电转换的三种场景

```text
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  场景1: 终端上下业务 \(必须光电转换\)                             │
│  ─────────────────────────────                               │
│  光信号进来 → 转成电信号 → 提取/插入客户业务 → 转回光信号       │
│                                                              │
│  线路光信号 ──▶ \[O/E\] ──▶ 电信号处理 ──▶ \[E/O\] ──▶ 线路光信号│
│                      │                                       │
│                 提取 VC-12/ODUk                               │
│                 插入新业务                                    │
│                                                              │
│  类比: 快递到了分拣中心，拆开包裹取出/放入物品                   │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  场景2: 电交叉调度 \(需要光电转换\)                               │
│  ─────────────────────────────                               │
│  光信号 → 转电 → 电层交叉 \(ODUk/VC-4 级别调度\) → 转回光       │
│                                                              │
│  西向光 ──▶ \[O/E\] ──▶ 电交叉盘 ──▶ \[E/O\] ──▶ 东向光          │
│                      │                                       │
│                 时隙\#7 → 时隙\#15                              │
│                 \(子波长级别精细调度\)                            │
│                                                              │
│  类比: 快递在分拣中心被拆包，重新分配到不同的车                  │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  场景3: 光交叉调度 \(不需要光电转换\)                              │
│  ─────────────────────────────                               │
│  光信号 → 直接在光层调度 \(波长级别\) → 光信号出去                │
│                                                              │
│  西向光 ──▶ 光交叉盘 ──▶ 东向光                                │
│            \(OXC\)                                             │
│            λ1 → 东向                                         │
│            λ2 → 南向                                         │
│            λ3 → 直通                                         │
│                                                              │
│  类比: 快递不拆包，直接换一辆车拉走                             │
└──────────────────────────────────────────────────────────────┘
```

## 三、电交叉盘——OEO 方式

### 3.1 工作原理

```text
电交叉盘: 光→电→交叉→电→光 \(OEO, Optical-Electrical-Optical\)

  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │  西向线路光信号                                               │
  │       │                                                      │
  │       ▼                                                      │
  │  ┌──────────┐                                                │
  │  │ O/E 转换  │  光信号 → 电信号                                │
  │  │ \(接收端\)  │  时钟恢复 + 数据判决                             │
  │  └────┬─────┘                                                │
  │       │                                                      │
  │       ▼                                                      │
  │  ┌──────────┐                                                │
  │  │ 成帧/解帧 │  提取 OTUk/ODUk/OPUk 帧结构                    │
  │  └────┬─────┘                                                │
  │       │                                                      │
  │       ▼                                                      │
  │  ┌──────────────────────────────────────────────────┐        │
  │  │              电交叉矩阵                            │        │
  │  │                                                    │        │
  │  │  ┌────────────────────────────────────────────┐   │        │
  │  │  │  交叉连接表:                                 │   │        │
  │  │  │                                              │   │        │
  │  │  │  入端口    入时隙    出端口    出时隙          │   │        │
  │  │  │  ──────────────────────────────────         │   │        │
  │  │  │  西向\#1    ODU2\#3   东向\#1   ODU2\#7        │   │        │
  │  │  │  西向\#1    ODU2\#5   支路\#2   ODU2\#1        │   │        │
  │  │  │  支路\#1    ODU2\#1   东向\#1   ODU2\#12       │   │        │
  │  │  │  \.\.\.                                        │   │        │
  │  │  └────────────────────────────────────────────┘   │        │
  │  │                                                    │        │
  │  │  交叉粒度: ODU0/ODU1/ODU2/ODU2e/ODU3/ODU4         │        │
  │  │  交叉容量: 256×256 \~ 1024×1024 个 ODUk             │        │
  │  └──────────────────────┬───────────────────────────┘        │
  │                         │                                    │
  │                         ▼                                    │
  │  ┌──────────┐                                                │
  │  │ 成帧     │  重新封装 OTUk/ODUk 帧                          │
  │  └────┬─────┘                                                │
  │       │                                                      │
  │       ▼                                                      │
  │  ┌──────────┐                                                │
  │  │ E/O 转换  │  电信号 → 光信号                                │
  │  │ \(发送端\)  │  激光器调制                                     │
  │  └────┬─────┘                                                │
  │       │                                                      │
  │       ▼                                                      │
  │  东向线路光信号 / 支路侧输出                                    │
  └──────────────────────────────────────────────────────────────┘
```

### 3.2 电交叉的核心能力

```text
电交叉盘能做什么？

  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │  ① 子波长调度 \(最核心\!\)                                       │
  │  ─────────────────────                                       │
  │  一个 100G 波长 \(ODU4\) 内部有 8 个 ODU2 \(10G\) 时隙            │
  │  电交叉可以:                                                  │
  │  ├── 提取其中任意一个 ODU2 → 送到支路盘 \(下业务\)               │
  │  ├── 从支路盘插入一个 ODU2 → 放入 ODU4 的空时隙 \(上业务\)       │
  │  └── 在不同 ODU4 之间搬移 ODU2 \(时隙转换\)                     │
  │                                                              │
  │  示例:                                                        │
  │  ┌──────────────────────────────────────────────────┐        │
  │  │  西向 ODU4 \(100G\):                                │        │
  │  │  ┌────┬────┬────┬────┬────┬────┬────┬────┐      │        │
  │  │  │ODU2│ODU2│ODU2│ODU2│ODU2│ODU2│ODU2│ODU2│      │        │
  │  │  │ \#1 │ \#2 │ \#3 │ \#4 │ \#5 │ \#6 │ \#7 │ \#8 │      │        │
  │  │  └──┬─┴──┬─┴──┬─┴────┴──┬─┴────┴────┴────┘      │        │
  │  │     │    │    │          │                         │        │
  │  │     │    │    │          └──▶ 东向 ODU4 时隙\#5     │        │
  │  │     │    │    └──▶ 支路盘\#2 \(10G 客户业务\)          │        │
  │  │     │    └──▶ 东向 ODU4 时隙\#2                     │        │
  │  │     └──▶ 支路盘\#1 \(10G 客户业务\)                    │        │
  │  └──────────────────────────────────────────────────┘        │
  │                                                              │
  │  ② 再生 \(3R\)                                                │
  │  ─────────────                                               │
  │  光信号经过长距传输后波形劣化                                   │
  │  电交叉: 光→电 \(重新判决\) → 电→光 \(生成全新光信号\)              │
  │  ├── Re-amplification: 再放大                                 │
  │  ├── Re-shaping: 再整形 \(恢复波形\)                             │
  │  └── Re-timing: 再定时 \(恢复时钟\)                              │
  │                                                              │
  │  ③ FEC 编解码                                                 │
  │  ─────────────                                               │
  │  接收: FEC 解码 → 纠错 → 提高信号质量                          │
  │  发送: FEC 编码 → 增加纠错能力                                 │
  │                                                              │
  │  ④ 告警检测与性能监控                                          │
  │  ─────────────────────                                       │
  │  检测: LOS/LOF/AIS/BDI 等告警                                 │
  │  监控: BIP 误码计数、FEC 纠错前/后误码率                        │
  └──────────────────────────────────────────────────────────────┘
```

### 3.3 电交叉的优缺点

```text
  优点:                          缺点:
  ├── 子波长精细调度              ├── 必须 OEO 转换 \(功耗大\)
  ├── 灵活上下业务                ├── 受限于电层速率 \(ASIC 固定\)
  ├── 3R 再生 \(恢复信号质量\)      ├── 升级困难 \(换板才能提速\)
  ├── FEC 纠错                    ├── 时延较大 \(OEO + 帧处理\)
  └── 完善的告警/性能监控          └── 成本高 \(复杂电芯片\)
```

## 四、光交叉盘——OOO 方式

### 4.1 工作原理

```text
光交叉盘 \(OXC\): 光→光层直接调度→光 \(无需光电转换\)

  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │  西向线路光信号 \(含 λ1\~λ80\)                                   │
  │       │                                                      │
  │       ▼                                                      │
  │  ┌──────────┐                                                │
  │  │ 光前置    │  放大微弱输入信号                                │
  │  │ 放大器    │                                                │
  │  └────┬─────┘                                                │
  │       │                                                      │
  │       ▼                                                      │
  │  ┌──────────────────────────────────────────────────┐        │
  │  │              光交叉矩阵 \(WSS / MEMS\)               │        │
  │  │                                                    │        │
  │  │  ┌────────────────────────────────────────────┐   │        │
  │  │  │  波长级调度:                                 │   │        │
  │  │  │                                              │   │        │
  │  │  │  入方向    波长      出方向                   │   │        │
  │  │  │  ─────────────────────────                  │   │        │
  │  │  │  西向      λ1       东向 \(穿通\)              │   │        │
  │  │  │  西向      λ2       东向 \(穿通\)              │   │        │
  │  │  │  西向      λ3       本地 \(下路\)              │   │        │
  │  │  │  西向      λ4       南向 \(调度\)              │   │        │
  │  │  │  南向      λ5       东向 \(调度\)              │   │        │
  │  │  │  本地      λ6       东向 \(上路\)              │   │        │
  │  │  │  \.\.\.                                        │   │        │
  │  │  └────────────────────────────────────────────┘   │        │
  │  │                                                    │        │
  │  │  调度方式:                                          │        │
  │  │  ├── WSS \(波长选择开关\): 每个输出端口独立选波长       │        │
  │  │  ├── MEMS \(微机电系统\): 微镜阵列反射到不同端口        │        │
  │  │  └── LCoS \(液晶硅\): 液晶控制波长路由                  │        │
  │  └──────────────────────┬───────────────────────────┘        │
  │                         │                                    │
  │                         ▼                                    │
  │  ┌──────────┐                                                │
  │  │ 光功率    │  均衡各波长功率                                  │
  │  │ 均衡 \(VOA\)│                                                │
  │  └────┬─────┘                                                │
  │       │                                                      │
  │       ▼                                                      │
  │  ┌──────────┐                                                │
  │  │ 光功率    │  放大到发送功率                                  │
  │  │ 放大器    │                                                │
  │  └────┬─────┘                                                │
  │       │                                                      │
  │       ▼                                                      │
  │  东向/南向 线路光信号                                          │
  └──────────────────────────────────────────────────────────────┘
```

### 4.2 WSS（波长选择开关）—— 光交叉的核心

```text
WSS 工作原理:

  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │  输入: λ1+λ2+λ3+\.\.\.+λ80 \(合波信号\)                           │
  │       │                                                      │
  │       ▼                                                      │
  │  ┌──────────────────────────────────────────────────┐        │
  │  │                                                  │        │
  │  │  ① 色散元件: 将合波光按波长分开                     │        │
  │  │     \(类似三棱镜分光\)                                │        │
  │  │                                                    │        │
  │  │     λ1 → 位置1                                     │        │
  │  │     λ2 → 位置2                                     │        │
  │  │     λ3 → 位置3                                     │        │
  │  │     \.\.\.                                            │        │
  │  │     λ80 → 位置80                                   │        │
  │  │                                                    │        │
  │  │  ② 光开关阵列: 控制每个波长的去向                    │        │
  │  │     \(MEMS 微镜 / LCoS 液晶\)                        │        │
  │  │                                                    │        │
  │  │     λ1 的微镜 → 反射到输出端口A                     │        │
  │  │     λ2 的微镜 → 反射到输出端口B                     │        │
  │  │     λ3 的微镜 → 反射到输出端口A                     │        │
  │  │     \.\.\.                                            │        │
  │  │                                                    │        │
  │  │  ③ 合波输出: 同一输出端口的波长重新合并               │        │
  │  │                                                    │        │
  │  │  输出端口A: λ1+λ3+λ5+\.\.\. \(东向\)                    │        │
  │  │  输出端口B: λ2+λ4+λ6+\.\.\. \(南向\)                    │        │
  │  │                                                    │        │
  │  └──────────────────────────────────────────────────┘        │
  │                                                              │
  │  WSS 关键能力:                                                │
  │  ├── 每个输出端口独立选择任意波长组合                          │
  │  ├── 支持 FlexGrid \(灵活栅格, 6\.25GHz 粒度\)                  │
  │  ├── 无色 \(Colorless\): 任意波长可去任意方向                    │
  │  ├── 无方向 \(Directionless\): 不限制输入方向                    │
  │  └── 无竞争 \(Contentionless\): 同波长可去不同方向               │
  └──────────────────────────────────────────────────────────────┘
```

### 4.3 光交叉的优缺点

```text
  优点:                          缺点:
  ├── 无需 OEO \(功耗极低\)         ├── 只能波长级调度 \(粒度粗\)
  ├── 透明传输 \(不限速率/格式\)     ├── 无法提取子波长 \(ODUk\)
  ├── 低时延 \(无帧处理\)           ├── 无法做 3R 再生
  ├── 速率无关 \(10G\~800G 通吃\)    ├── 无法做 FEC 编解码
  ├── 未来可扩展 \(升级无需换硬件\)   ├── 功率均衡复杂
  └── 容量极大                    └── 无法检测电层告警
```

## 五、光交叉 vs 电交叉——对比

```text
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  对比项          电交叉              光交叉                    │
│  ──────────    ──────────────    ──────────────              │
│  交换方式       OEO \(光→电→光\)    OOO \(光→光\)                 │
│  交换粒度       ODUk \(子波长\)      波长 \(λ\)                   │
│  最小单位       ODU0 \(1\.25G\)      一个波长 \(100G/200G/400G\)   │
│  调度灵活性     极高 \(精细到时隙\)   中 \(波长级\)                 │
│  功耗           高 \(OEO 转换\)      低 \(纯光\)                   │
│  时延           较大 \(μs 级\)       极小 \(ns 级\)                │
│  3R 再生        支持               不支持                      │
│  FEC           支持               不支持                      │
│  速率透明       不透明 \(固定速率\)   透明 \(任意速率\)             │
│  告警检测       完善               仅光层 \(LOS/LOF\)            │
│  未来演进       需换硬件            软件可升级                   │
│  成本           高                 中 \(但 ROADM 系统整体高\)     │
│  典型应用       上下业务/再生站      穿通/波长调度                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 六、实际设备中的协同——光电混合交叉

```text
现代 OTN 设备: 光交叉 + 电交叉 协同工作

  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │  西向光 \(λ1\~λ80\)                                             │
  │       │                                                      │
  │       ▼                                                      │
  │  ┌──────────────────────────────────────────────────┐        │
  │  │              光交叉盘 \(OXC / WSS\)                  │        │
  │  │                                                    │        │
  │  │  λ1 → 东向 \(直通，纯光，无需 OEO\)                  │        │
  │  │  λ2 → 东向 \(直通\)                                  │        │
  │  │  \.\.\.                                               │        │
  │  │  λ60 → 东向 \(直通\)                                 │        │
  │  │  λ61 → 本地 ↓ \(下路到电交叉\)                       │        │
  │  │  λ62 → 本地 ↓ \(下路到电交叉\)                       │        │
  │  │  本地 ↑ → λ63 \(上路，从电交叉来\)                    │        │
  │  │  本地 ↑ → λ64 \(上路，从电交叉来\)                    │        │
  │  └──────────────────────┬───────────────────────────┘        │
  │                         │                                    │
  │          λ61 下路 ↓     │     ↑ λ63 上路                     │
  │          λ62 下路 ↓     │     ↑ λ64 上路                     │
  │                         │                                    │
  │  ┌──────────────────────┴───────────────────────────┐        │
  │  │              电交叉盘 \(ODUk 交叉\)                  │        │
  │  │                                                    │        │
  │  │  λ61 下路 → O/E → ODU4 → 提取 ODU2\#3 → 支路盘     │        │
  │  │  λ62 下路 → O/E → ODU4 → 提取 ODU2\#1 → 支路盘     │        │
  │  │  支路盘 → ODU2 → 插入 ODU4 → E/O → λ63 上路       │        │
  │  │  支路盘 → ODU2 → 插入 ODU4 → E/O → λ64 上路       │        │
  │  │                                                    │        │
  │  │  同时:                                              │        │
  │  │  λ61 中 ODU2\#5 → 搬到 λ63 的 ODU4 时隙\#2 \(时隙转换\) │        │
  │  └──────────────────────────────────────────────────┘        │
  │                                                              │
  │  东向光输出:                                                  │
  │  λ1\~λ60 \(直通\) + λ63\(上路\) + λ64\(上路\)                       │
  │  \= 62 个波长纯光直通 + 2 个波长经过电交叉处理                   │
  │                                                              │
  │  效率: 62/64 \= 97% 的波长无需 OEO\!                            │
  └──────────────────────────────────────────────────────────────┘
```

## 七、光电混合交叉的优势

```text
为什么需要光电混合？

  纯电交叉:
  ┌──────────────────────────────────────────────────────────┐
  │  所有 80 个波长都要 OEO → 功耗巨大、成本高                  │
  │  80 × 100G \= 8T 电交叉容量 → 电芯片成本极高                │
  └──────────────────────────────────────────────────────────┘

  纯光交叉:
  ┌──────────────────────────────────────────────────────────┐
  │  无法提取子波长 → 不能上下 2M/10G 等小颗粒业务              │
  │  无法做 3R 再生 → 长距传输信号质量无法恢复                   │
  └──────────────────────────────────────────────────────────┘

  光电混合 \(最优解\!\):
  ┌──────────────────────────────────────────────────────────┐
  │  大部分波长 \(穿通\) → 光交叉处理 \(低功耗、低时延\)            │
  │  少量波长 \(上下路\) → 电交叉处理 \(精细调度、3R、FEC\)         │
  │                                                           │
  │  典型比例:                                                │
  │  ├── 光交叉处理: 80\~90% \(穿通波长\)                        │
  │  └── 电交叉处理: 10\~20% \(上下路波长\)                       │
  │                                                           │
  │  效果:                                                    │
  │  ├── 功耗降低 60%+                                        │
  │  ├── 成本降低 40%+                                        │
  │  ├── 保留子波长调度能力                                    │
  │  └── 保留 3R/FEC 能力                                     │
  └──────────────────────────────────────────────────────────┘
```

---

## 八、总结

> **电交叉是&quot;精细手术刀&quot;（子波长调度），光交叉是&quot;高速公路立交&quot;（波长直通），现代设备用光电混合方式兼顾效率和灵活性。**

|对比维度|电交叉盘|光交叉盘|光电混合|
| ----------| -----------------------| ----------------------| ----------------|
|**交换方式**|OEO (光→电→光)|OOO (光→光)|两者结合|
|**交换粒度**|ODUk (1.25G\~100G)|波长 (100G\~400G)|波长+子波长|
|**功耗**|高|低|中 (最优)|
|**时延**|μs 级|ns 级|混合|
|**3R 再生**|支持|不支持|电交叉部分支持|
|**FEC**|支持|不支持|电交叉部分支持|
|**适用场景**|上下业务/再生|穿通/波长调度|所有场景|
|**未来趋势**|逐步减少比例|比例持续增大|主流架构|

## 三、第1层：映射——客户信号装入 ODUk

```text
每种客户信号都有标准的映射方式:

  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │  ① 2M \(E1\) → ODU0                                           │
  │  ─────────────────                                           │
  │  2\.048 Mbit/s → 异步映射 \(AMP/GMP\) → ODU0 \(1\.25G\)           │
  │                                                              │
  │  ┌──────────────────────────────────────┐                    │
  │  │  ODU0 \(1\.25G\)                        │                    │
  │  │  ┌──────────────────────────────┐    │                    │
  │  │  │ OPU0 净荷                     │    │                    │
  │  │  │ ┌──────────┬────────────┐   │    │                    │
  │  │  │ │ 2M 信号   │ 码速调整    │   │    │                    │
  │  │  │ │ \(2\.048M\)  │ \(GMP\)      │   │    │                    │
  │  │  │ └──────────┴────────────┘   │    │                    │
  │  │  └──────────────────────────────┘    │                    │
  │  │  + ODU0 开销 \(TTI/BIP-8/PT\)          │                    │
  │  └──────────────────────────────────────┘                    │
  │                                                              │
  │  ② GE → ODU0                                                │
  │  ─────────────                                               │
  │  1\.25 Gbit/s → 异步映射 \(GMP\) → ODU0 \(1\.25G\)                │
  │  \(GE 速率 ≈ ODU0 净荷，刚好能装下\)                             │
  │                                                              │
  │  ③ 10GE → ODU2 / ODU2e                                      │
  │  ─────────────────────                                       │
  │  10\.3125 Gbit/s → 异步映射 \(AMP\) → ODU2e \(10G\)               │
  │  9\.953 Gbit/s \(STM-64\) → 异步映射 → ODU2 \(10G\)               │
  │                                                              │
  │  ④ 100GE → ODU4                                             │
  │  ─────────────────────                                       │
  │  103\.125 Gbit/s → 异步映射 \(AMP\) → ODU4 \(100G\)               │
  │  \(100GE 速率 \> ODU4 净荷，需要码速调整\)                        │
  │                                                              │
  │  映射核心: GMP \(Generic Mapping Procedure\)                    │
  │  ────────────────────────────────────                        │

  │  ├── 正调整: 插入空闲字节 \(客户信号慢\)                          │
  │  ├── 负调整: 删除冗余字节 \(客户信号快\)                          │
  │  └── 零调整: 不调整 \(速率刚好匹配\)                              │
  └──────────────────────────────────────────────────────────────┘
```

## 九、总结

> **支路盘复用线路传输**  **=**  **4 步：映射（装入容器）→ 复用（小容器装大容器）→ 封装（加开销+FEC）→ 调制（电→光）。**

|步骤|功能|输入|输出|
| ------| -------------------------| ------------------| ----------------|
|**映射**|客户信号适配标准容器|2M/GE/10GE/100GE|ODU0/ODU2/ODU4|
|**复用**|低阶 ODUk 装入高阶 ODUk|多个 ODU0/ODU2|ODU4 (含时隙)|
|**封装**|加段开销 + FEC|ODU4|OTU4|
|**调制**|电信号调制到光载波|OTU4 (电)|1550nm 光波长|

**关键数字**：

|数字|含义|
| ------| ----------------------------|
|**8**|1 个 ODU4 \= 8 个 ODU2|
|**8**|1 个 ODU2 \= 8 个 ODU0|
|**32**|1 个 ODU4 \= 32 个 ODU0|
|**111.810 Gbit/s**|OTU4 线路速率|
| **~100 Gbit/s**|ODU4 净荷速率|
