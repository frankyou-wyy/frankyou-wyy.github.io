# ROADM OXC全光网

## 一、为什么需要 ROADM / OXC？

### 传统 OTN 的痛点

```text
传统 OTN 网络中，每个波长经过中间站时的处理：

  A站 ──λ1──▶ B站（中间站）──λ1──▶ C站

  B站的处理（传统方式）：
  ┌──────────────────────────────────┐
  │  λ1 光信号到达                   │
  │       │                         │
  │       ▼                         │
  │  光→电转换（O/E）← 线路盘接收    │
  │       │                         │
  │       ▼                         │
  │  电交叉调度 ← 交叉盘            │
  │       │                         │
  │       ▼                         │
  │  电→光转换（E/O）← 线路盘发送    │
  │       │                         │
  │       ▼                         │
  │  λ1 继续传输                    │
  └──────────────────────────────────┘

  问题：
  · 每个穿通波长都要 O/E/O 转换
  · 96 个波长 = 96 对光模块做穿通
  · 功耗巨大、成本高、时延大
  · 大量光模块被浪费在"穿通"上
```

### ROADM / OXC 的解决方案

```text
ROADM / OXC：让穿通波长"不落地"直接通过

  A站 ──λ1──▶ B站（ROADM/OXC）──λ1──▶ C站

  B站的处理（全光方式）：
  ┌──────────────────────────────────┐
  │  λ1 光信号到达                   │
  │       │                         │
  │       ▼                         │
  │  WSS/OXC 直接调度 ← 光域操作！   │
  │       │                         │
  │       ▼                         │
  │  λ1 继续传输（全程是光信号）      │
  └──────────────────────────────────┘

  效果：
  · 穿通波长不需要 O/E/O 转换
  · 96 个波长中 90 个穿通 → 90 个不落地
  · 只有 6 个需要上下路 → 才做 O/E/O
  · 功耗降低 60%+，成本大幅降低
```

## 二、ROADM 详解

### 2.1 ROADM 是什么

**ROADM（Reconfigurable Optical Add/Drop Multiplexer，可重构光分插复用器）** ——可以在**光域**灵活地上下路/穿通波长，无需 O/E/O 转换。

### 2.2 ROADM 的核心组件

```text
ROADM 节点结构：

                    线路侧（西向）
                        │
                   ┌────▼────┐
                   │  WSS    │ ← 波长选择开关
                   │ (West)  │    逐波调度
                   └──┬───┬──┘
                      │   │
              穿通波长 │   │ 下路波长
                      │   │
                   ┌──▼┐ ┌▼──────────┐
                   │WSS│ │ 分波器     │
                   │   │ │ (DEMUX)   │
                   │   │ └──┬──┬──┬──┘
                   │   │    │  │  │
                   │   │   λ1 λ2 λ3  → 下到支路盘（O/E 转换）
                   │   │
                   └──┬──┘
                      │
              上路波长 │ + 穿通波长
                      │
                   ┌──▼────┐
                   │  WSS   │ ← 合波
                   │(East)  │
                   └───┬────┘
                       │
                    线路侧（东向）

关键组件：
  · WSS（Wavelength Selective Switch）：（波长选择开关）逐波调度，核心器件
  · DEMUX/MUX：分波/合波
  · VOX（Variable Optical Attenuator）：可变光衰减器，功率均衡
```

### 2.3 WSS —— ROADM 的灵魂

```text
WSS 功能：
  · 输入：合波信号（λ1~λn）
  · 对每个波长独立控制：
    - 穿通到某个方向
    - 下路到本地
    - 调节光功率
  · 输出：重新组合的合波信号

WSS 端口示例（1×9 D WSS）：
  1 个输入口
  9 个输出口（8 个方向 + 1 个本地上下路）

  每个波长可以被独立切换到任意输出口：
  λ1 → 输出口1（东向穿通）
  λ2 → 输出口3（南向穿通）
  λ3 → 输出口9（本地上下路）
  λ4 → 输出口1（东向穿通）
  ...
```

### 2.4 ROADM 的代际演进

|代际|名称|方向数|特点|
| ------| ----------------------------| ---------------| ------------------------------|
|**1代**|固定 ROADM（F-ROADM）|2 方向|上下路波长固定，不能远程重构|
|**2代**|可重构 ROADM（C-ROADM）|2\~4 方向|WSS 实现远程重构上下路|
|**3代**|方向无关 ROADM（CD-ROADM）|任意方向|波长可从任意方向上下路|
|**4代**|方向+端口无关（CDP-ROADM）|任意方向+端口|波长可从任意端口上下路|

```text
代际演进示意：

1代 F-ROADM：
  西向 ←── 固定波长上下路 ──→ 东向
  · λ1~λ3 固定上路，λ4~λ6 固定下路
  · 改不了，要改就得换硬件

2代 C-ROADM：
  西向 ←── WSS 灵活调度 ──→ 东向
  · 任意波长可远程配置上下路
  · 但只能从固定端口上下路

3代 CD-ROADM：
  西向 ←──┐
  东向 ←──┤ WSS 灵活调度
  南向 ←──┤
  北向 ←──┘
  · 任意波长可从任意方向上下路
  · 真正的"方向无关"

4代 CDP-ROADM：
  · 不仅方向无关，端口也无关
  · λ1 可以从任意 WSS 端口的任意位置上下路
```

## 三、OXC 详解

### 3.1 OXC 是什么

**OXC（Optical Cross-Connect，光交叉连接器）** ——在 ROADM 基础上进一步集成，将**合波器、分波器、WSS、光放**等集成到一个"光背板"中，实现**全光交叉**。

### 3.2 OXC vs ROADM

```text
传统 ROADM 节点：
┌──────────────────────────────────────────┐
│  设备子架                                 │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   │
│  │线路盘 │ │WSS盘 │ │光放盘 │ │线路盘 │   │
│  │(西向) │ │      │ │      │ │(东向) │   │
│  └──┬───┘ └──┬───┘ └──┬───┘ └───┬──┘   │
│     │        │        │         │       │
│  ┌──┴────────┴────────┴─────────┴──┐    │
│  │         背板（电信号）            │    │
│  │   波长之间通过线缆连接            │    │
│  │   大量光纤跳线！                  │    │
│  └─────────────────────────────────┘    │
│                                          │
│  问题：子架间大量光纤跳线                 │
│       → 运维复杂、故障率高、占用空间      │
└──────────────────────────────────────────┘

OXC 节点：
┌──────────────────────────────────────────┐
│  设备子架                                 │
│  ┌──────┐ ┌──────────────────┐ ┌──────┐ │
│  │线路盘 │ │   OXC 光背板      │ │线路盘 │ │
│  │(西向) │ │                  │ │(东向) │ │
│  └──┬───┘ │  全光交叉矩阵     │ └───┬──┘ │
│     │     │  · WSS 集成       │     │    │
│     │     │  · 光波导连接     │     │    │
│     │     │  · 无光纤跳线     │     │    │
│     │     └──────────────────┘     │    │
│     └──────────────────────────────┘    │
│                                          │
│  优势：无光纤跳线                         │
│       → 运维简单、故障率低、体积小         │
└──────────────────────────────────────────┘
```

### 3.3 OXC 的核心技术

|技术|说明|优势|
| ------| ----------------------------------------| --------------------|
|**LCOS（硅基液晶）**|WSS 核心器件，逐波控制相位实现光束偏转|端口数多、灵活度高|
|**光波导（PLC）**|平面光波导替代光纤跳线|无跳线、高可靠|
|**集成光放**|EDFA 集成在 OXC 内部|减小体积|
|**光背板**|所有光信号在背板内全光调度|零跳纤、即插即用|

### 光电混合交叉（实际部署方式）

```text
实际 OXC/ROADM 节点中：

  96 个波长到达节点：
  
  ┌────────────────────────────────────────────┐
  │                                            │
  │  85 个穿通波长 → 光交叉（WSS/OXC）直接穿通  │
  │  · 不落地、不 O/E/O                         │
  │  · 功耗低、时延小                           │
  │                                            │
  │  11 个上下路波长 → 下到电交叉盘              │
  │  · O/E 转换后进入电交叉                      │
  │  · 电交叉完成 ODUk 调度                     │
  │  · 需要 3R 再生的也在这里处理                │
  │                                            │
  └────────────────────────────────────────────┘

  → 这就是"光电混合交叉"
  → 光交叉处理穿通（效率优先）
  → 电交叉处理上下路和再生（功能优先）
```

## 五、ROADM/OXC 关键能力

|能力|说明|价值|
| ------| --------------------------------| ------------------|
|**波长级灵活调度**|任意波长可切换到任意方向|网络拓扑灵活调整|
|**无色上下路**|上下路波长不受端口限制|波长规划简化|
|**无竞争上下路**|同一波长可在不同方向同时上下路|频谱利用率提升|
|**光功率自动均衡**|VOX 自动调节各波长功率|减少人工调测|
|**CD 补偿**|内置色散补偿模块|减少 DCF 使用|
|**光层保护**|光层 1+1 / 光线路保护|\< 50ms 倒换|

## 六、ROADM/OXC 与传统 OTN 对比

|对比项|传统 OTN|ROADM/OXC|
| --------| ----------------------------| -------------------------|
|**穿通方式**|O/E/O 电穿通|全光穿通|
|**波长调度**|固定配置，改配需人工|远程软件配置，秒级调整|
|**光纤跳线**|大量跳线|OXC 无跳线|
|**功耗**|高（每个穿通波长都 O/E/O）|低（穿通不耗电）|
|**时延**|高（O/E/O 处理时延）|低（光穿通几乎零时延）|
|**可扩展性**|差（扩容需加板卡+跳线）|好（软件配置即可）|
|**运维复杂度**|高|低|
|**成本**|设备便宜但运维贵|设备贵但运维便宜|
|**适用场景**|小站点、少量波长|核心/汇聚节点、大量波长|

## 七、全光网演进路线

```text
阶段1：点到点 OTN（当前主流）
  A ════ OTN ════ B
  · 每个站都 O/E/O
  · 适合小网络

阶段2：FOADM（固定光分插复用）
  A ════ FOADM ════ B ════ FOADM ════ C
  · 中间站固定上下路部分波长
  · 不能远程重构

阶段3：ROADM（可重构光分插复用）
  A ════ ROADM ════ B ════ ROADM ════ C
  · 中间站可远程重构上下路波长
  · 需要 SDN 控制器配合

阶段4：OXC（全光交叉）
  A ════ OXC ════ B ════ OXC ════ C
  · 全光交叉，无跳纤
  · 光电混合交叉，效率最高

阶段5：全光网 2.0（终极目标）
  · 端到端全光传输
  · 从接入到骨干全程光域调度
  · SDN 控制器全局智能管控
```

## 八、一句话总结

> **ROADM** 通过 WSS 实现波长级的**光域灵活调度**——穿通波长不落地、不 O/E/O，只有上下路波长才做光电转换，大幅降低功耗和时延；**OXC** 是 ROADM 的**集成升级版**——将 WSS、合分波器、光放等集成到光背板中，彻底消除光纤跳线，实现"零跳纤"全光交叉。两者在实际部署中采用**光电混合交叉**架构：大部分波长通过光交叉穿通（效率优先），少量波长下到电交叉做 ODUk 调度和 3R 再生（功能优先），配合 SDN 控制器实现波长级的远程灵活调度，是全光网从"电交换为主"走向"光交换为主"的核心技术。
