### 2.2 核心知识点

```text
Week 1-2: WDM 光层基础
──────────────────────────────────────────────────
  ├── 光的基本概念
  │   ├── 波长  nm、频率f  Hz、频谱   通信用 1310/1550nm波长
  │   ├── 光功率p \(dBm 分贝豪瓦\)  光的强弱，0dBm=1mW

  │
  ├── WDM 原理
  │   ├── CWDM: 粗波分 \(18 波长, 20nm 间隔\)
  │   ├── DWDM: 密集波分 \(80/96 波, 50GHz/100GHz 间隔\)
  │   └── FlexGrid: 灵活栅格 \(6\.25GHz 粒度\) 按需分配频谱

  │   └── OA 噪声累积与 OSNR 计算
  │   ├── BA (Booster Amplifier): 发送端功率放大  目标: 提高发送功率，延长传输距离
  │   ├─ ─LA (Line Amplifier): 线路中间中继放大   目标: 补偿光纤损耗，延长传输距离
  │   └── PA (Pre-Amplifier): 接收端前置放大     目标: 放大微弱信号，提高接收灵敏度

      ├── CD \(色度色散\)
      ├── PMD \(偏振模色散\)

Week 3-4: OTN 帧结构与开销
──────────────────────────────────────────────────

  │   ├── OCH \(光通道层\)
  │   ├── ODUk \(光数据单元\)
  │   ├── OPUk \(光净荷单元\)
  │   └── OTUk \(光传送单元\)
  │
  ├── OTUk 帧结构
  │   ├── 帧大小: 4行 × 4080列
  │   ├── FAS \(帧对齐信号\)
  │   ├── SM \(段监控开销\)
  │   ├── GCC \(通用通信通道\)
  │   └── FEC \(前向纠错区域\)
  │
  ├── ODUk 帧结构与开销
  │   ├── PM \(通道监控开销\)
  │   ├── TCM \(串联连接监控\)
  │   ├── APS/PCC \(保护倒换\)
  │   └── TTI \(通道追踪\)
  │
  └── 对比 SDH 理解差异
      ├── SDH: SOH → OTN: OTUk SM
      ├── SDH: POH → OTN: ODUk PM
      ├── SDH: FEC 无 → OTN: SD-FEC/HD-FEC
      └── SDH: 指针 → OTN: 无指针 \(异步映射\)

Week 5-6: OTN 复用映射
──────────────────────────────────────────────────
  ├── 客户信号 → OPUk → ODUk → OTUk
  │   ├── 2M E1 → OPU0 → ODU0 → OTU0
  │   ├── GE → OPU1 → ODU1 → OTU1

  │
  └── 对比 SDH 复用
      ├── SDH: VC-12→TUG-2→TUG-3→VC-4 \(3×7×3\)
      ├── OTN: ODU0→ODU1→ODU2→ODU3→ODU4
      └── 关键区别: OTN 无指针，采用异步映射 \(AMP\)

Week 7-8: 相干光通信
──────────────────────────────────────────────────
  ├── 为什么需要相干
  │   ├── 100G+ 速率下直接检测的局限
  │   ├── 相干检测的灵敏度优势
  │   └── 数字信号处理 \(DSP\) 的作用 ，用算法替代光域补偿，完成全部解调
```

#### 各模块功能

|模块|全称|功能|
| ------| ----------------------| ---------------------------|
|**OTU**|光波长转换单元|将客户信号转换为标准波长|
|**OMU**|光复用器（合波器）|将多个波长合到一根光纤|
|**ODU**|光解复用器（分波器）|将一根光纤中的波长分开|
|**OSC**|光监控通道|1510nm，传输管理/监控信息|

#### CWDM vs DWDM 对比

|对比项|CWDM|DWDM|
| --------| -------------------------| --------------------------------|
|**波长间隔**|20nm|0.8nm (100GHz) / 0.4nm (50GHz)|
|**波长数量**|18 波|80/96 波 (C 波段)|
|**光源**|非制冷激光器|制冷激光器|
|**光放大器**|不支持 EDFA|支持 EDFA|
|**传输距离**|\< 80km|1000km+|
|**单纤容量**|18 × 10G \= 180G|80 × 400G \= 32T|
|**成本**|低 (1/3 \~ 1/5 DWDM)|高|
|**应用场景**|城域接入、短距|骨干、城域核心、长距|

#### 光放大器故障与运维

```text
常见故障与排查:

  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │  ① 输入光功率过低                                             │
  │     现象: 告警 "Input Low" / "LOS"                            │
  │     原因: 上游光纤断裂 / 上游光放故障 / 连接器脏污              │
  │     排查: 用光功率计测输入 → 检查上游 → 清洁连接器              │
  │                                                              │
  │  ② 输出光功率异常                                             │
  │     现象: 输出功率偏高/偏低                                    │
  │     原因: 泵浦激光器老化 / 增益控制异常                        │
  │     排查: 检查泵浦电流 → 对比历史数据 → 更换光放盘              │
  │                                                              │
  │  ③ OSNR 劣化                                                  │
  │     现象: 误码率升高 / FEC 纠错计数增加                         │
  │     原因: 多级 EDFA 噪声累积 / 非线性效应                      │
  │     排查: 用光谱仪测 OSNR → 检查各级光放增益                    │
  │                                                              │
  │  ④ 增益平坦度劣化                                              │
  │     现象: 部分波长误码，部分正常                                │
  │     原因: GFF 老化 / 波长数量变化                               │
  │     排查: 光谱仪检查各波长功率 → 调整 VOA \(可变光衰减器\)        │
  │                                                              │
  │  运维注意事项:                                                 │
  │  ├── 永远不要直视光纤端面 \(激光伤害眼睛\)                        │
  │  ├── 清洁连接器必须用专用清洁工具                               │
  │  ├── 光功率变化 \> 2dB 需要排查                                 │
  │  └── 定期用光谱仪检查 OSNR 和增益平坦度                         │
  └──────────────────────────────────────────────────────────────┘

改善 OSNR 的优先级
  ① 提高入纤功率 (最简单，+2dB 功率 → +2dB OSNR)
  ② 降低 NF (用低噪声 EDFA 或 Raman)
  ③ 使用超低损耗光纤 (G.654.E)
  ④ 减少级联数 (OXC 全光交换，消除光电中继)
```

> **光放大器**  **=**  **WDM 系统的&quot;接力站&quot;，让光信号不用光电转换就能直接放大，从而实现上千公里的传输。**

|核心要点|内容|
| ----------| ----------------------------------------------------------|
|**EDFA**|绝对主力，掺铒光纤+泵浦激光，C/L 波段放大|
|**三种角色**|BA(发送端功率放大)、LA(线路中继放大)、PA(接收端前置放大)|
|**ASE 噪声**|每级 \~5dB，级联越多 OSNR 越低，限制传输距离|
|**增益平坦**|GFF 滤波器让各波长增益一致，否则功率失衡|
|**Raman**|分布式放大，超低噪声，与 EDFA 混合用于超长距|
|**关键数字**|增益 15\~30dB，噪声 4\~6dB，泵浦 980/1480nm|
